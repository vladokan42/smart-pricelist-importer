# Проверки и ограничения

## Воспроизводимые офлайн-проверки

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

58 тестов проверяют:

- точную привязку ответа к исходным строкам, дубли индексов, повреждённый JSON и ограниченные повторы;
- неизменность исходного файла, отказ от перезаписи результата, гонку записи и отсутствие частичного JSON;
- явную ставку НДС, нулевую и отсутствующую ставку; жирность или чужое число не заменяет НДС;
- точное совпадение ОКПД2 со словарём без сокращения/исправления кода, передачу словаря модели и предел 64 КиБ;
- неоднозначные колонки цены, сохранение неизвестных значений, цены упаковки и округление через Decimal;
- формулы, внешние связи XLSX, макросы, размер, распаковку ZIP, символические и жёсткие ссылки;
- сохранение ведущих нулей, больших идентификаторов и многострочного CSV.

Сеть в этих тестах заменена контролируемыми ответами. Они проверяют программу, а не качество конкретной модели.

## Реальная интеграционная проверка

Перед публикацией выполнен отдельный запуск с реальной моделью через OpenAI-совместимый сервер, без подмены HTTP-ответа. На входе — только созданный `examples/create_demo.py` синтетический XLSX:

- четыре товара, два листа;
- ставки результата: `0.1`, `0`, `null`, `null`;
- все четыре кода выбраны из двухкодового демонстрационного словаря;
- исходная книга осталась неизменной;
- исходные цены `110`, `80`, `125` сохранились; товар без цены остался без неё;
- результат действительно записан в JSON и прочитан обратно.

Это узкая проверка связки Excel → модель → проверки → JSON, **не оценка точности классификации на произвольных товарах**. Код, существующий в справочнике, всё равно требует проверки человеком. В публичный репозиторий не включены адрес проверочного сервера, ключи, служебные пути или ответы на рабочие данные.

## Известные границы

- Автономная версия рассчитана на тематический справочник до 65 536 байт UTF-8 JSON. Полный классификатор нужно предварительно разделить на проверенные тематические наборы; автоматического поиска и выбора подмножества нет.
- Старый XLS возвращает сохранённые значения; обнаружение исходных формул через xlrd недоступно. Совместимость с каждым вариантом чужих XLS не заявляется.
- XLSX-формулы не вычисляются. Формульные денежные поля не становятся подтверждённой ценой только из-за наличия кэша.
- Нет кэша обогащения, слияния товаров, записи в каталог, почты или автоматического обновления справочников.
- Для атомарного создания результата нужна файловая система с поддержкой жёстких ссылок. Папка результата должна существовать. При успешной записи и отказе `fsync` папки выдаётся предупреждение об устойчивости к отключению питания; полный JSON не удаляется.
- JSON использует обычные числовые значения; точное исходное текстовое представление цены остаётся в данных происхождения.
