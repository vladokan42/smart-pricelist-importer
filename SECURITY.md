# Безопасность и приватность

## Перед запуском

- В комплекте нет рабочих прайс-листов, поставщиков, цен, баз данных или учётных данных. Примеры создаются из вымышленных строк.
- Используй только файлы, которые имеешь право обрабатывать. Прайс-лист может содержать коммерческую тайну и персональные данные.
- Перед запуском проверь всю книгу, включая скрытые листы: существующий обработчик читает все содержательные листы, а не только открытый в Excel. Неожиданные приватные колонки тоже могут попасть в контекст модели.
- При запуске обработки с моделью содержимое строк и контекст Excel отправляются на указанный тобой OpenAI-совместимый сервер. Если этот сервер обращается к внешнему провайдеру, данные покидают твою машину. Локальный адрес шлюза сам по себе не означает локальную модель.
- Секрет задаётся через переменную окружения `LLM_API_KEY`. Не коммить `.env`, ключи, ответы модели, исходные рабочие книги или результат импорта.
- Не запускай программу от root. Не загружай непроверенные файлы в публичный сервер: это локальный инструмент, а не защищённый многопользовательский веб-сервис.

## Границы результата

ОКПД2 — предложение классификации, а не юридическое заключение. Наличие кода в справочнике подтверждает существование кода, но не правильность его применения к товару.

Ставка НДС принимается из явного исходного значения; её отсутствие не заменяется процентом из общих знаний модели. Нулевая ставка и неизвестная ставка — разные состояния. Правомерность применения налога проверяет человек по документам и действующим правилам.

Текст ячеек передаётся как недоверенные данные. Проверки ответа модели снижают риск изменения структуры и значений, но не делают вывод модели безошибочным.

## Сообщить об уязвимости

Используй вкладку **Security → Report a vulnerability**, если она доступна, либо создай Issue с обезличенным описанием. Не публикуй секреты и рабочий файл. Достаточно версии Python, идентификатора коммита, минимального синтетического примера и ожидаемого поведения.
